八个功能

不做重量级编辑器，只把报销、归档、发文件时最常做的那几件事做顺手。

合并与整理

几个 PDF 拼成一个，拖缩略图改顺序，不要的页点掉。中间可以插入图片，单独成一页。

图片 → PDF

发票、截图、照片合成一个 PDF。JPEG 原样嵌入不重新编码，画质和原图一致。

PDF → 图片

每页存成一张图。默认 600 DPI，比印刷精度还高，放大看文字边缘也不糊。

拆分与抽页

点缩略图挑页，攒够一份就开下一份，每份用不同颜色标出来，导出成各自的文件。也能每页一份或每 N 页一份。

PDF 转文字版

扫描件和图片版 PDF 变成能搜索、能复制的文字版，中英混排也认。识别在本机完成，三平台通用。

压缩到指定大小

填个目标大小，比如 2MB，自动找合适的压缩档位。对付报销系统和邮箱附件限制。

水印

对角或平铺，参数一改立刻看到效果。水印是图形不是文字，对方选不中也删不掉。

盖章 / 贴图

电子章、签名图拖到页面上，缩放旋转到合适位置再导出。透明 PNG 不会带白底。

常见问题

会上传我的文件吗？

不会。所有 PDF 与图片处理都在你的电脑上完成，断网也能正常使用。唯一的网络请求发生在激活或续期时，只发送激活码和一段不可逆哈希后的设备标识。

没有激活码能用吗？

可以打开、载入文件、看每一项处理的效果（缩略图、识别结果、水印预览等），导出文件时需要激活码。

换电脑了怎么办？

激活码支持换机转移，在新电脑上重新输入即可。转移次数用尽后可联系客服协助解绑。

扫描件转文字版效果如何？

使用系统内置的识别引擎，中英文混排的印刷体效果很好。导出的仍是 PDF，原图不动，文字作为隐藏层叠加——排版不变，但能搜索、能复制。建议先用「识别预览」确认效果。

压缩会不会把文件弄糊？

压缩会按你设定的目标体积自动搜索质量档位，体积压得越狠画质损失越大，这是无法避免的取舍。纯文字类 PDF 可压缩空间有限，软件会如实告知结果。

macOS 提示「已损坏，无法打开」怎么办？

这不是文件损坏，是 macOS 对未做 Apple 公证的应用的默认拦截。两种处理方式：
① 在「应用程序」里找到 Paperbox，右键（或 Control+单击）→ 打开，在提示里再点一次「打开」，之后就能正常双击了；
② 若仍提示已损坏，打开「终端」执行 xattr -cr /Applications/Paperbox.app，这行命令只清除浏览器下载时打的隔离标记，不修改应用本身。
DMG 里附了同样的说明。后续会补上 Apple 公证，届时不再需要这步。

Windows 提示「Windows 已保护你的电脑」？

SmartScreen 对下载量还不多的新程序会默认拦一道。点窗口左下角「更多信息」→「仍要运行」即可，只需第一次这样。

支持哪些系统？

支持 macOS 14+（Apple 芯片与 Intel）、Windows 10/11 64 位、Linux x86_64（AppImage）。三个平台功能完全一致，八项功能都可用。
